# 0001 · 侧栏双形态:经典列表为默认,城市视图可切换

- 状态:已定(2026-08-29,grill-with-docs 决策轮 Q3)
- 背景:视觉规范重构后,形态基准 `ui-prototype/composite-tui/composite-tui-proto.html` 的侧栏是经典列表(嵌题线 §2.13 + 反显行 §2.10 + SET D 图标 §2.5);真仓侧栏当时已是城市视图(`renderer/src/ui/sidebar-city/`,多轮迭代产物)。

## 决策

- 保留城市视图 ⇄ 常规侧栏的切换功能,两种形态都维护。
- **默认形态 = composite 经典侧栏**;落地前先按官方 3080 侧栏做口径核查(inspector 截基准图),在 composite demo 中**补齐官方功能入口与 UI**,确认后才落真仓。
- 城市视图不平移规范细节;新规范(反显/嵌题/图标)只要求落在经典侧栏,城市视图的样式统一另立任务。

## 取舍与后果

- 备选 A(规范翻译到城市视图、废弃经典)被否:demo 侧栏承载的入口形态是官方 1:1 口径的基准,城市视图是附加形态,不能喧宾夺主。
- 备选 B(废城市视图)被否:城市视图是用户多轮裁决的既有投入。
- 后果:侧栏存在两套渲染面,规范更新需评估是否双面生效;切换入口本身属「新增独有功能」,不受 §8 铁律约束,但官方入口在两种形态下都不得缺失。
