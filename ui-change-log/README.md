# ui-change-log — UI 删除/破坏性改动记账本

本目录用于记录 deepseek-zion 在 UI 风格改造中**删除或破坏性改动**了复刻 dsh web 展示内容的情况。

铁律见 [`AGENTS.md`](../AGENTS.md):**改 UI 优先改样式;确需删除既有展示元素/交互入口时,必须先在此目录记录,再动手删除。**

## 规则

- 每条记录一个文件,按日期命名:`YYYY-MM-DD--简短slug.md`。
- 记录必须包含四要素:
  1. **删除了什么**(界面元素 / 交互入口 / 功能语义);
  2. **为什么删**(视觉原因 / 功能原因);
  3. **替代方案**(若为样式问题,应优先样式改写保留功能;此处说明为何样式改写不可行);
  4. **验证方式**(API/探针/目测,证明不影响用户可达功能)。
- 记录提交后,再提交删除本身的代码改动;两个提交分开,便于追溯。

## 约定

- 仅记录对**复刻 dsh web UI 部分**的删除/破坏性改动;新增独有功能无需记录。
- `ui-change-log` 目录本身是本规则的记账本,不是可删除的展示内容。
