磁带纹思考块 · 动效三变体 — TAPE VARIANTS / V0 现状对照

磁带身份不变(竖划横轨 + 拖尾 + Matrix 绿),变的是「什么在动」。全部数值从现有实现出发,只改运动模型。
V0 · 现状走带(对照)竖划以 2.2px/帧 整体右移,6% 热头,出屏即回卷
▾THINKING· 思考中…
问题:每根划都在动 → 全轨均匀「输送带」感,与雨(固定网格 + 移动亮度)不同源;热头是随机散布,不读「进度/节奏」。
V1 · 亮度波(LUMINANCE WAVE)划固定不动,一道亮度波扫过栅格;波头近白,波尾衰减回 40% 档
▾THINKING· 思考中…
…检索候选规范的组织方式对位 Primer 的 foundations 分层
概念:与数字雨同一原理(Rezmason:字形固定、移动的是亮度)——磁带变成「栅格」,思考是扫过栅格的能量。收益:与雨同族、运动最克制;波的一次往返 ≈ 一次「想完一段」的节拍。
V2 · 幅度包络(VU ENVELOPE)走带保留,但划高随行进的正弦包络起伏——像磁带电平表,峰值处出热头
▾THINKING· 思考中…
…比较三种运动模型的辨识度包络相位与走带速度解耦
概念:走带是「带在转」,包络是「带上有信号」——VU 表式的呼吸感,最「活」。收益:不增任何元素就有节奏层次;峰值热头给出视觉锚点。
V3 · 段落突发(BURST WRITE)常时慢速漂移;每隔 1.2–2.5s 一次写脉冲:整段加速 3 倍 + 前沿一道白热头,随后归于漂移
▾THINKING· 思考中…
…突发间隔随机化避免节拍器感亮头只在脉冲前沿,一次一个
概念:思考是「分段写出来」的——漂移=酝酿,脉冲=落笔。收益:叙事性最强(有开始/峰值/余波);脉冲之间的静场让动效更珍贵。
组合 · V3 主态 + V1 闭环慢波流式 = 突发写脉冲;闭环 = 低亮度慢波呼吸(替代冻结帧)
▸THINKING· 12.4s
闭环态 · V1 慢波:速度约为流式 1/2(一波 ~12s,可察但不抢戏),峰值封顶 55%、无白热——呼吸即「已沉降」,比冻结帧多一点余温。
▾THINKING· 思考中…
…漂移段:酝酿下一段脉冲段:整段落笔,前沿一道白热头
主态 · V3 突发:漂移 = 酝酿,脉冲 = 落笔。两态同框时,闭环慢波明显「让位」于流式突发,层级自然成立。
备选组合:V1 也可作静态帧以外的「闭环态低亮度慢波」。所有变体的闭环/非流式静态帧沿用现口径(rgba(20,184,80,0.28) 冻结帧),reduced-motion 一律静态帧。
