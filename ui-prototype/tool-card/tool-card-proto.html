规则卡

① 框线即全部容器:无圆角、无阴影、无底色块——「卡」只是 1px 线的围合。② 标题嵌顶边不占内容行;图标 = SET D(currentColor 随框线档)。③ 态只走亮度档:常态 40 / 运行 70(+ 扰码图标)/ 错误 = 全屏唯一语义红;不设第四态色。④ 内容行 = C01 ⎿ 续行,折叠/展开为整行点击(与官方 toggle 语义一致)。⑤ 被替代物:现有工具卡底色块 + 左侧色条 + 圆角。
